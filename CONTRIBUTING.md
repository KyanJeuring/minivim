# Contributing to MiniVim

Thanks for your interest in contributing to **MiniVim**

## Philosophy
MiniVim is designed to be:
- Simple
- Predictable

Please keep changes aligned with these goals.

---

## How to contribute

### 1. Fork the repository

Create a fork and clone it locally.

### 2. Create a feature branch

```bash
git checkout -b feature/my-feature
```

### 3. Make your changes

Avoid unnecessary external dependencies

Prefer readability over cleverness

### 4. Test manually

Test the NeoVim configuration locally.

### 5. Submit a Pull Request

Use the PR template and describe:

What you changed

Why it’s useful

Any breaking changes

---

## Versioning

This project uses semantic versioning:

MAJOR – breaking changes

MINOR – new features

PATCH – bug fixes
